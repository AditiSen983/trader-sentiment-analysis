# Trader Performance vs Market Sentiment

## Objective

Analyze how market sentiment (Fear/Greed) impacts trader behavior and performance.

## Tools Used

* Python (Pandas, NumPy)
* Matplotlib
* Google Colab

## Key Analysis

* Daily PnL vs Sentiment
* Trading activity vs Sentiment
* Behavioral patterns of traders

## Insights

* Traders perform better during Greed phases.
* Trading activity increases during Greed.
* Fear leads to cautious trading behavior.

## Strategy Recommendations

* Reduce leverage during Fear periods.
* Increase trading cautiously during Greed phases.

## How to Run

1. Open the notebook in Google Colab
2. Upload datasets
3. Run all cells

## Note

This project focuses on extracting actionable insights within limited time.
